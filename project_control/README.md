3. `03_AUTOMATIONS.md` — tareas programadas activas, propósito y cadencia.
4. `04_INCIDENTS_AND_FINDINGS.md` — hallazgos de producción y problemas abiertos.
5. `05_ROADMAP.md` — prioridades, siguiente trabajo y definición de terminado.
6. `06_WORKING_RULES.md` — reglas para ChatGPT/Codex/QA/deploy para no romper lo estable.

## Regla principal

Cada nuevo avance importante debe dejar solo cuatro cosas claras aquí: qué cambió, qué quedó probado, qué sigue abierto y cuál es el siguiente paso. No duplicar informes completos dentro de este directorio.
