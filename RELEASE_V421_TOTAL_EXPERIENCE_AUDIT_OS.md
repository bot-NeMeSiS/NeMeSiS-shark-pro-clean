# NeMeSiS SHARK PRO V421 — Total Experience Audit OS

Objetivo: reorganizar la app completa para que cliente y admin no sufran pantallas infinitas, mezclas de información ni textos internos fuera de sitio.

## Cliente
- Home final por objetivos.
- Live Center limpio.
- Picks Center limpio.
- Mi cuenta separada por centros.
- Alertas, ayuda y favoritos con pantallas propias.
- Menos scroll continuo.
- Modo simple primero y profundidad bajo demanda.

## Admin
- Admin OS separado por centros.
- Usuarios, señales, Live, Combi, Telegram y Sistema separados.
- Herramientas internas bajo desplegable técnico.
- Render/API/DB/QA fuera de cliente.

## Verificación
- Build listo para GitHub + Render.
- No se añaden llamadas API externas.
- Compatible con SQLite/Persistent Disk.
