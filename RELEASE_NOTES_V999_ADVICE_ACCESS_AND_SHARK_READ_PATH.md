# V999 — Advice access and SHARK read path

Candidate under validation. This document is not a production or full-v1 certificate.

Paid-advice presentation now checks the actual session entitlement and the current stored pick status/tier before exposing a shared enriched sports snapshot. The shared sports cache, fixture ownership and global sports count contracts remain principal-independent. Anonymous/FREE readers receive no advice, legacy FREE advice still starts at PRO, and unknown or higher tiers fail closed. Current active surfaces omit rows withdrawn, deleted or settled after the cache was populated. Selected authorized resolved advice remains supported through the existing independent selection boundary.

The boundary covers public/signed-in Home presentation, compact/full client presentation, SHARK featured cards and briefing, the picks page/API and the realtime sports response. The realtime validator runs after filtering and varies by Cookie. Admin authority is unchanged; a paid commercial plan grants no administrative role. No production accounts were used in the reproductions.

SHARK reuses only the sports metrics just returned by its own validated live collection operation. It no longer rebuilds unused Home/live/customer-trust presentation or overwrites compact presentation values at the end of the view. It does not introduce a global metrics cache, reuse a copied proof, or extend freshness leases. Closed Server-Timing fields separate input, allowance, context and rendering; nested fields are children of assistant_context, and view_total is an inclusive parent. Do not sum parents with children. No question, pick identifier, user data or provider payload is included in timing names.
