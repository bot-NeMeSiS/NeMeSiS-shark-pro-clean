# NeMeSiS SHARK PRO V401.0 — Global UX Organization OS

Objetivo: ordenar toda la app para que cliente y admin no sufran agobio visual ni pantallas infinitas.

Incluye:
- Centros de cliente: Home, Live, Picks, Combi, SHARK y Perfil.
- Centros admin: resumen, usuarios, picks, live ops, combi ops y sistema.
- Guardrails anti-scroll infinito.
- Home ligera y admin operativo por zonas.
- Modo simple primero y modo PRO/desplegables para profundidad.
- Sin gasto extra API.

Base: V400 UX Anti-Agobio Home Minimal Premium.
