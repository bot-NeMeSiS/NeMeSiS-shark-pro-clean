# Continuity

Read `project_control/CURRENT_TRUTH.md` and the active section of
`docs/NEMESIS_RECONCILIATION_AUDIT.md` before editing. Verify current Git refs,
the candidate and existing changes; historical chats and reports do not prove
that work is still pending. Preserve unrelated work and recovery sources.

Use the single identified consolidation candidate. Do not resurrect an old
branch, repeat an integrated task, or interpret session grouping as shared
memory or expanded permission. Production, merge and deployment require
separate explicit authorization.
