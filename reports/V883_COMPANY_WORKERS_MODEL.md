# V883 Company Workers Model

V883 introduce un empleado interno permanente: `SHARK Visual Worker`.

## Workers internos
- CEO/Product Owner Worker.
- Visual QA Worker.
- Mobile QA Worker.
- Admin Operations Worker.
- Data/API Worker.
- Picks/Odds Worker.
- Telegram Worker.
- SHARK IA Worker.
- Payments/Memberships Worker.
- Security Worker.
- Render/DevOps Worker.
- Release Manager Worker.
- Spanish Copy Worker.
- Sentinel Workflow Worker.

Cada worker devuelve estado, hallazgos, tareas, prioridad y siguiente accion segura.

## Limites
- No modifica codigo automaticamente.
- No despliega.
- No toca secretos.
- No toca DB real.
- No envia Telegram real.
- No toca pagos reales.
- No inventa datos.
