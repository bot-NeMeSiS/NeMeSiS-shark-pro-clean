# V871 Reducción Real de Huecos

## Aplicado en CSS
- Headers y heroes con `min-height: 0` y padding responsive.
- Cards con padding `clamp()` más compacto.
- Empty states reducidos sin perder claridad.
- KPI strips y grids con gap menor.
- Filas de partido/listas más densas.
- Tablas admin con filas más compactas.
- Móvil con `overflow-x: clip` y grids a una columna cuando procede.

## Resultado esperado
Cliente PC debe sentirse más dashboard, móvil más app nativa y admin más command center compacto.

## Límite
No se añadieron widgets con datos falsos. Si no hay datos, se mantiene estado seguro.
