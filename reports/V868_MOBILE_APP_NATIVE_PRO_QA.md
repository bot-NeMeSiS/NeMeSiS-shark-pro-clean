# V868 Pro Max - Mobile App Native Pro QA

## Objetivo
Consolidar el móvil como app nativa premium: header compacto, marca clara, bottom nav estable, SHARK flotante sin tapar navegación, cards compactas y estados claros.

## Cambios aplicados
- Refuerzo CSS Pro Max para cards compartidas, botones, chips, pick cards, match rows, empty states y Sentinel cards.
- Protección adicional contra overflow horizontal en filas de partido, códigos largos y acciones móviles.
- Mantiene bottom nav y floating SHARK sin duplicados evidentes.
- Se conserva la supresión de elementos cliente dentro de admin.
