# Message Style Guide

## Identidad

Todos los mensajes de NeMeSiS deben parecer parte del mismo producto:

🦈 NeMeSiS SHARK PRO
━━━━━━━━━━━━━━━━━━
Título claro
Contexto breve
──────────────
Fuente, evidencia, calidad, frescura y limitaciones

## Principios

1. Claro antes que espectacular.
2. Compacto antes que largo.
3. Evidencia antes que opinión.
4. Riesgo visible antes que promesa.
5. Hora Madrid cuando exista contexto temporal.
6. Nunca simular información deportiva ausente.
7. Nunca presentar una hipótesis como hecho.

## Reglas de longitud

- Mensaje completo: objetivo menor de 10 segundos de lectura.
- Máximo técnico protegido: 3900 caracteres para Telegram.
- Bloques: una idea por bloque.
- Párrafos largos: no permitidos en mensajes automáticos.

## Prohibido

- "Seguro" como promesa de resultado.
- "Ganancia garantizada".
- "Apuesta obligatoria".
- Ocultar limitaciones.
- Mezclar varias acciones principales en el mismo bloque.
- Mensajes con `None`, `null`, `undefined`, mojibake o placeholders visibles.
