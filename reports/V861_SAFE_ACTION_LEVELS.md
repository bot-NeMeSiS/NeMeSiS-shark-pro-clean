# V861 Safe Action Levels

## LEVEL_1_DIAGNOSTIC_ONLY

- Leer estado.
- Generar reportes.
- Crear checklist.
- Generar recomendaciones.

## LEVEL_2_SAFE_AUTO_HEAL

- Refrescar diagnósticos internos.
- Preparar tareas.
- Detectar duplicados.
- Recalcular reportes.

## LEVEL_3_REQUIRES_ADMIN_APPROVAL

- Enviar Telegram test.
- Lanzar sync grande.
- Recalcular picks.
- Archivar picks.
- Modificar membresías.
- Preparar release.
- Limpiar legacy dudoso.

## LEVEL_4_FORBIDDEN_AUTOMATIC

- Modificar código.
- Hacer deploy.
- Tocar secretos.
- Borrar datos.
- Modificar pagos reales.
- Enviar Telegram masivo.
- Inventar datos deportivos o comerciales.
