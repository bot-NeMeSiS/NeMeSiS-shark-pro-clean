# V836 Real Data State And Empty State QA

## Reglas preservadas

- Futuro = Próximo.
- Live real = En directo.
- Final con marcador = Resultado.
- Pasado sin marcador = Resultado pendiente.
- Falta proveedor = Esperando proveedor.
- Sin logo real = fallback premium.
- Sin picks = Sin picks activos.
- Sin cuotas = Cuotas pendientes.
- Madrid Time siempre.

## Restricciones mantenidas

- No se inventan partidos.
- No se inventan resultados.
- No se inventan cuotas.
- No se inventan picks.
- No se inventan minutos/eventos/stats.
- No se inventa ROI.
- No se descargan logos durante render.
- No se escribe SQLite desde rutas de imagen.
