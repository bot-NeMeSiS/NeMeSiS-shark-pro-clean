# V861 Codex Prompt Generator Notes

## Objetivo

El motor genera prompts sugeridos para Codex, pero no los ejecuta.

## Ejemplos incluidos

- Auditar Render real contra runtime local.
- Corregir visual móvil con capturas reales.
- Revisar Telegram si no hay envíos.
- Revisar picks sin cuotas.
- Preparar hotfix si aparece un error de header invalid value.
- Auditar pagos/membresías si Stripe no está configurado.

## Límite

Los prompts son texto copiable. La app no se reescribe sola.
