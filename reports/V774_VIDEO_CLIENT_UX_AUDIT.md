# Auditoría de vídeo cliente V774

## Problema visto

Los vídeos mostraban que la app había acumulado muchas capas de mejoras pero sin una jerarquía clara para el cliente. La navegación era demasiado larga, varias pantallas repetían bloques de modo automático/Mundial/mercados, y el cliente podía perderse entre secciones que parecían internas o secundarias.

## Decisión de producto

La experiencia cliente queda ordenada con este flujo diario:

1. Inicio.
2. Partidos.
3. Directo.
4. Picks.
5. SHARK.
6. Histórico.
7. Más para herramientas secundarias.

## Criterios aplicados

- No todo debe estar arriba.
- Las funciones secundarias no se eliminan; se agrupan.
- Cada pantalla debe tener una misión clara.
- Cada partido debe enseñar fecha, hora Madrid, estado y acceso al detalle.
- Cada pick debe enseñar selección, mercado, cuota, stake, riesgo y motivo.
- No se inventan datos si faltan.

## Pantallas atacadas

- Home cliente.
- App Center.
- Calendario.
- Directo.
- Picks.
- Combis.
- Mercados.
- Resúmenes.
- Track Record.
- Detalle de partido.
- Sports Hub.
- Menú Más.

## Resultado esperado tras desplegar

La app debe sentirse menos como un conjunto de paneles añadidos y más como una aplicación comercial donde el cliente sabe qué hacer primero.
