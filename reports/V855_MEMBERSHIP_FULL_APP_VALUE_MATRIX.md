# V855 Membership Full App Value Matrix

Motor creado: `engines/membership_experience_engine.py`.

FREE:
- Útil pero limitado.
- Acceso a partidos, directo, estados reales y SHARK básico.
- CTA: Subir a PRO.

PRO:
- Más valor en picks explicados, Telegram premium, track record y soporte prioritario.
- CTA: Ver ELITE.

ELITE:
- SHARK avanzado, Telegram top, análisis ampliado y prioridad visual.
- Acento visual dorado.

ELITE+:
- Acceso prioritario y máxima profundidad cuando hay datos reales.

ADMIN:
- No es membresía cliente.
- Command center para datos, Telegram, SHARK, usuarios, pagos, runtime y automatización.

Aplicación por pantalla:
- Home/app: comunica valor del plan.
- Partidos/live/picks: estados bloqueados seguros cuando falten permisos o datos.
- SHARK: diferencia profundidad sin inventar datos.
- Telegram: comunica valor premium sin inventar envíos.
- Perfil/membresías/pagos: presenta upgrade sin tocar pagos reales.
