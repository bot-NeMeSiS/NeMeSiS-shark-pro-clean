# V939 Definiciones del embudo de cliente

| Etapa | Evidencia minima |
|---|---|
| visitor | Evento anonimo consentido; actualmente no estimado. |
| registered | Usuario persistido. |
| active | Login o sesion observada dentro de la ventana definida. |
| pro_interest | Vista real de membresias/upsell. |
| checkout_started | Sesion de checkout registrada. |
| pro_customer | Membresia PRO persistida y coherente. |
| elite_customer | Membresia ELITE/ELITE+ persistida y coherente. |
| renewed | Evento de renovacion verificado. |
| cancelled | Cancelacion persistida. |

Una etapa no se infiere de la siguiente ni se completa con ceros artificiales.
