# V862 Sentinel Admin QA

## Panel admin

Pantalla creada: `/admin/shark-sentinel`

Alias:

- `/admin/app-inspector`
- `/admin/qa-bot`
- `/admin/bot-auditor`

## Qué muestra

- Estado del bot auditor.
- Perfiles revisados.
- Matriz de rutas.
- Modelo de incidencias.
- Acciones seguras.
- Acciones con aprobación.
- Prompts sugeridos para Codex.
- Endpoints seguros.

## Protección

Las APIs admin devuelven 403 sin sesión admin.
