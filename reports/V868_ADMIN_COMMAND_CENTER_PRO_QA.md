# V868 Pro Max - Admin Command Center Pro QA

## Objetivo
Admin debe sentirse como sala de control: denso, claro, sobrio y sin elementos cliente.

## Aplicado
- Refuerzo de cards admin y Sentinel.
- Supresión explícita de bottom nav, floating SHARK y scroll-top cliente dentro de `.ns-admin`.
- Tablas y cards conservan lectura compacta.
- Códigos largos y rutas tienen overflow controlado.

## Paneles preservados
- Dashboard.
- Company OS.
- Company Audit.
- Data Center.
- API-SPORTS.
- Telegram Command Center.
- SHARK AI.
- Daily Automation.
- Users, memberships y payments.

## Seguridad
No se muestran secretos y las APIs admin siguen requiriendo sesión.
