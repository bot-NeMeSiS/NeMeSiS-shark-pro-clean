# V845 SHARK Pick Explanation QA

La integración de pick permite explicar:
- partido;
- mercado;
- selección;
- cuota real o `Cuotas pendientes`;
- stake si existe;
- confianza si existe;
- riesgo;
- motivo real.

Botones revisados:
- `/picks` usa `Explicar pick con SHARK`.
- Match detail usa `Explicar pick con SHARK`.

SHARK no crea picks si no existe un pick publicado.
