# V813 Visual Reference QA Report

## Objetivo

Pulir la experiencia visual sin importar nuevos recursos ni rehacer la UI. Se mantiene el logo real `static/img/shark-logo.svg` como identidad principal.

## Aplicado

- Fondo SHARK más controlado, sin tapar contenido.
- Topbar cliente más compacta.
- Tarjetas y paneles con radios más consistentes.
- Menos altura visual en móvil.
- Bottom nav móvil más útil y menos invasiva.
- Admin con paneles algo más compactos y jerarquía más clara.
- SHARK flotante oculto cuando el usuario ya está en `/shark`.

## No aplicado

- No se importaron frames del vídeo ni imágenes del ZIP de referencia para evitar añadir material pesado o no validado.
- No se cambió la identidad visual principal.
- No se crearon pantallas nuevas.

## Resultado

La interfaz conserva V812, pero queda más vendible y compacta en escritorio, tablet y móvil.
