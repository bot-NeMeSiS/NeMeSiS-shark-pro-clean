# V817 Mobile Reference QA

## Objetivo

Acercar el cliente a una app nativa en 390px/430px sin rehacer logica.

## Ajustes

- Bottom nav centrada, compacta y fija.
- Cards con padding reducido y bordes consistentes.
- SHARK flotante reducido en movil para no tapar navegacion.
- Tiburon decorativo suavizado en movil.
- Titulares limitados para evitar pantallas gigantes.
- Filas de partido pasan a una columna cuando el ancho no permite tres columnas.

## Riesgo residual

No se generaron capturas reales con navegador en esta sesion. La validacion se apoya en HTML renderizado, parse Jinja, smoke tests y checks especificos.
