# V927 Workforce PC Panel QA

El panel de Workforce usa una fila compacta de estados y una rejilla operativa de dos zonas. Release Manager, Runtime Verifier, Post-Deploy Sentinel, Secret Guard, Browser QA, Visual Queue, Telegram Watcher y Reporting Worker conservan sus estados reales.

Browser QA y la cola visual no se presentan como resueltos cuando faltan screenshots. Deploy real sigue condicionado a autorizacion y secretos de entorno.
