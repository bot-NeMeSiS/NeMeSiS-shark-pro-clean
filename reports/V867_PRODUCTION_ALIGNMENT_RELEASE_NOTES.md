# V867 production alignment release notes

V867 no añade features nuevas. Su objetivo es certificar que producción Render ya sirve V866 y preparar un paquete V867 limpio para cerrar el ciclo de alineación.

## Probado en real
- Runtime Render.
- Rutas públicas básicas.
- APIs admin protegidas sin sesión.
- Cron/automation sin secret.

## Probado local
- Versionado V867.
- Runtime local.
- Checks de compatibilidad.
- Sentinel estático.
- ZIP limpio.

## Pendiente
- Deploy manual de V867 si se quiere que producción pase de V866 a V867.
