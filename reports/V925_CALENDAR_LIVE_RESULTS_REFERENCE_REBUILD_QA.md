# V925 Calendar, Live and Results Reference Rebuild QA

## Safe contexts

- `get_safe_sports_calendar_context()` exposes matches/results, provider state, sync/cache state, source and a safe message.
- `get_safe_live_context()` separates live, upcoming and finished events and exposes provider state.
- Live rendering is cache-first. An external refresh is only attempted through explicit `?refresh=1` behavior.

## UI result

- Calendar, aliases and sports views keep V923 route recovery.
- Calendar displays compact status KPIs, filters and existing match rows.
- Live displays En vivo, Próximos and Finalizados with an honest empty state.
- Results and scores appear only from available source data.
- Missing crests retain the existing visual fallback; no official crest is fabricated.

## Data rules

No team, competition, minute, score or result is generated by the V925 presentation layer. Provider/cache failure returns a safe page instead of a 500 or a blocking external request.
