# Digital Employees Report

## Scope

El termino empleado digital se implementa como revisor determinista, no como asistente ficticio, IA generativa ni chatbot.

## Reviewers

| revisor | modulo | responsabilidad |
| --- | --- | --- |
| Product Director | Producto | Valida valor, integracion y complejidad del producto. |
| UX Reviewer | UX | Revisa navegacion, onboarding, claridad, jerarquia y accesibilidad. |
| Mobile Reviewer | Mobile | Revisa una mano, scroll, targets tactiles, safe areas y responsive. |
| Sports Reviewer | Sports Core | Valida coherencia deportiva y consumo del Sports Core. |
| SHARK Reviewer | SHARK | Comprueba evidencia, frescura, procedencia y limitaciones. |
| Security Reviewer | Seguridad | Audita privacidad, permisos, secretos, sesiones y almacenamiento. |
| Performance Reviewer | Rendimiento | Analiza tiempos, assets, cache, consultas y rendimiento movil/escritorio. |
| Commercial Reviewer | Comercial | Evalua FREE, PRO, ELITE, conversion, paywall y retencion. |
| Marketing Reviewer | Marketing | Revisa propuesta de valor, mensajes, CTA, diferenciacion y posicionamiento. |
| Beta Reviewer | Beta | Simula recorridos reales y detecta friccion antes de beta cerrada. |
| Visual Reviewer | Visual | Detecta espacios vacios, iconografia, color, tipografia y consistencia. |
| Operations Reviewer | Operaciones | Audita Render, cron, master tick, gateway, logs, backups y restore. |


## Execution Rules

- No inventar observaciones.
- Toda observacion exige evidencia.
- Toda propuesta queda como candidata y requiere decision humana.
- Ningun revisor modifica codigo, datos, produccion, Telegram o Stripe.
