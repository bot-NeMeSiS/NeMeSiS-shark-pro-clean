# Cómo instalar V604

1. Descomprime este ZIP.
2. Copia todo su contenido encima de tu carpeta actual `NeMeSiS shark pro`.
3. Acepta reemplazar archivos.
4. Verifica en Render que existe `SECRET_KEY`.
5. Sube a GitHub y despliega.
6. Prueba:
   - `/`
   - `/cliente-login`
   - `/admin-login`
   - `/api/v604/security-check`

Esta actualización no incluye `.git`, `__pycache__`, base de datos ni ZIPs internos.
