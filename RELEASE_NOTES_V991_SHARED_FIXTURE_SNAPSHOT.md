# V991 — shared fixture snapshots

Candidate status: the local gates below cover their stated cases; final CI and the
material large-cohort Directo CPU gate remain open. This is not a published release.

Home, Calendar and Directo select complete original observations through the same
operation-owned fixture evidence. Filters precede grouping and presentation limits.
Historical rows retain their own bounded cohort and unknown/conflicting occurrences
remain visible without fabricated action IDs.

The coordinator admits a LIVE original only when the source's validated LIVE
collection approves that same object and its own evidence is still fresh. This
happens before preparation, so Home, Calendar, Directo and their grouped counts
cannot independently promote an unapproved nominal LIVE status. Reusing the
getter within one request preserves the prepared owner; changed identity is not
re-prepared into new trusted evidence.

Home recomputes current user favorites, picks, status and date from intact copies.
The legacy ranking hint cannot authorize cached user flags or a cached profile.
This is a correctness change, not a classification-cache speedup.

Directo and the existing generic realtime bars opt into explicit grouped contracts.
Each score, minute, statistic and expiry remains tied to its own provider observation.
Unknown/unavailable counts render as unavailable; a verified empty read can report zero.
The first server-rendered page also distinguishes an unavailable read, without
JavaScript, in Spanish, English and French.
Weak validators for the new consumers retain identity, source clocks, status and scope;
legacy consumers retain their existing response. Historical lock notices preserve the
available cards without claiming that a historical read was complete.

Modern matches-only GET consumers can prepare the same source evidence without
building unused Home and legacy metrics payloads. Full summaries remain the default;
switching modes within one request retains the same owner and prepared identity
anchors. The stored cache payload and its original acceptance checks are unchanged.

Directo uses a smaller explicit presentation context through its existing safe
wrappers. It retains session validation, degraded-state reporting, authenticated
auditing and fresh metric reads after the remaining callbacks. Other compact and
full consumers keep their existing context. Descriptor generation reads state and
issues from one fresh checked context, after converting the original action ID.

Validation before integration: 182 real-App RAM contract checks; 563 real HTTP checks
over 91 GET requests; a separate 48-check/6-GET absent-versus-empty gate; frontend
67 Directo, 43 metadata, 23 isolated Chromium checks and one normalizer case.
Managed-source validation: 410 pure component tests; 102 Home/language cases;
57 Directo/calendar WSGI cases; eight actual Chromium cases on desktop/mobile;
ten fresh-worker real-App contracts; 25 isolated QA file-restoration/predicate
checks; 45 release/PWA/language cases and the V915 safety checker. These gates
overlap and are not a combined pytest total. The fresh-worker gate is included
in CI, with isolated synthetic storage and no providers or real accounts.

Follow-up managed gates: 139 historical/Calendar/metrics/LIVE admission cases,
159 Home/language/Directo/Calendar WSGI cases, and eight actual Chromium desktop
and mobile cases. They passed with isolated synthetic storage and no external
connections. The eight browser cases are explicitly excluded from the WSGI gate
and executed separately. Counts from these scopes must not be added to older
overlapping validation totals or treated as a production certificate.

Home and Calendar no longer construct an unused realtime projection. The guarded
call-observation regression demonstrates one-to-zero calls on those routes while
used Directo/API projections remain active. This is not a global speed benchmark.

No provider calls, schema, quotas, financial rules, credentials, rights or service
configuration changed. The experimental scalar memo was rejected: it did not
demonstrate a robust speedup. The 800-observation projection has a material measured
local CPU/payload cost; this release does not certify cold/global performance.
Backup capacity, a real certified copy/restore, comprehensive provider coverage and
the remaining V1000 program gates remain open.
