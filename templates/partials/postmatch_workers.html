Qué permite esta activación y qué no

Activar consultas no es certificar derechos. Este control solicita datos a las API seleccionadas, conserva estadísticas con su fuente y guarda enlaces de resúmenes para revisión. No descarga vídeos ni los autoriza por pagar una suscripción.

Las condiciones públicas de TheSportsDB permiten desarrollar aplicaciones y servicios mediante su API, respetando sus límites y atribución. El contenido de terceros requiere una base de uso independiente. No se revende el acceso a su API desde este módulo.

Los vídeos, fotografías, miniaturas y escudos no obtienen permisos por esta activación. Un enlace o una marca de Creative Commons no sustituyen la revisión del recurso y de su uso previsto.
