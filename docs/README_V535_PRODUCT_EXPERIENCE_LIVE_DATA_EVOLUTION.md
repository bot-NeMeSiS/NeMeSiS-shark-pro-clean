# V535 — Product Experience & Live Data Evolution

Build enfocada en convertir NeMeSiS SHARK PRO en una experiencia cliente más compacta, clara y comercial.

## Incluye
- UX más compacta con menos scroll y mejor jerarquía visual.
- Picks HOT y fallback inteligente cuando no hay picks publicados.
- Partidos próximos reales como base de análisis sin inventar apuestas.
- Live Center más vivo y visual.
- Favoritos inteligentes reforzados.
- Match Detail y Team Hub conservados.
- Combi Builder con selector de número de partidos.
- SHARK IA flotante y contextual conservado.
- Separación cliente/admin reforzada.
- Diagnóstico `/api/product-experience-check`.

## Política de datos
No se inventan partidos ni picks como reales. Si no hay datos, se muestra estado premium claro y CTA correcto.

## Deploy
Render-ready. Mantener `DB_PATH=/data/database.db`.
