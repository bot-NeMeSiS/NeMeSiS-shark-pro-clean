# V961 — More useful calendar space on desktop and mobile

Wide calendar country and tournament sections now balance their league cards into two columns while keeping each league together and retaining the existing one-column flow on smaller screens. This reduces the unused gaps created when a tall league forces a whole grid row to match its height.

The calendar sort option uses the shorter, localized “Relevance” label, and its mobile control keeps a predictable width. Search, filtering, ordering values, match data, permissions, and provider calls are unchanged.
