# V975 — Hora propia para cada estadística del partido

El Centro de Partido conserva y muestra la hora de recepción de cada valor local y visitante cuando esa hora existe. La última hora global de Directo ya no se reutiliza como si describiera las estadísticas; la línea de conjunto usa la señal estadística más reciente o la hora de sincronización guardada.

Los datos sin hora siguen sin recibir una fecha inventada. La presentación se mantiene compacta en escritorio y móvil, con etiquetas localizadas en español, inglés y francés. No añade llamadas al proveedor, cambios de datos ni alteraciones de la frecuencia de actualización.

Validación: regresiones de contexto, HTML, frescura, localización, contratos de interfaz y compilación; verificar la matriz completa antes de publicar.
