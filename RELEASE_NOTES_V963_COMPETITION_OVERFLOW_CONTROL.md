# V963 — Control claro para el resto de competiciones

En calendarios con muchas competiciones, el control para mostrar las que no caben en la navegación principal ahora tiene apariencia de acción, conserva un objetivo táctil de 44 px y muestra un signo distinto al expandir o contraer.

El texto cambia entre «Ver N competiciones más» y «Mostrar menos competiciones», con traducciones para inglés y francés. El comportamiento usa el elemento nativo `details`, por lo que sigue funcionando sin JavaScript. No cambia los partidos, el orden, los filtros ni las llamadas a proveedores.
